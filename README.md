# Blog code samples

Runnable code for posts at [knourian.ir](https://knourian.ir).

Each top-level folder matches a post slug and contains its own solution. Build and run a sample from this repository root:

```bash
dotnet run --project how-async-work-flows-in-csharp/TaskFlow
```

The related post links to the exact source files it discusses. Samples use public APIs where network access is part of the example.
